## F02 单联系人老人主界面

验证时间：2026-08-31 16:02（Asia/Shanghai）

### 自动化门禁

1. JVM 单元测试通过：姓名归一化、空姓名、Unicode 码点上限和重复点击门禁。
2. 目标真机 instrumentation 测试 3/3 通过：
   - 姓名和照片写入应用私有目录后可重载；
   - 仅更新姓名时保留已有照片；
   - 无法解码的伪图片被拒绝。
3. 严格 Android Lint 通过，0 个错误、0 个警告。

### 实机界面与交互

1. 首次启动显示家属设置页；在 1.45 倍系统字体下，标题、说明、照片、姓名输入框和保存按钮均位于可见区域内。

3. 照片按钮向可访问性树暴露“给Family打视频电话”，姓名和操作提示均完整显示。
4. 连续点击照片只触发一次受控反馈；F03 尚未完成时明确显示“通话服务尚未开启，请家属继续设置”。
5. 强制停止后冷启动成功，临时联系人配置仍能恢复。
6. UI 测试后已清除临时联系人和测试照片，并卸载 instrumentation 测试 APK；KinCall 主应用保留在首次设置页。
7. 验证期间未发现 KinCall 的 `FATAL EXCEPTION` 或 ANR。

结论：F02 通过目标真机功能与可见输出验收。
