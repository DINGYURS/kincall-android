## F02 单联系人老人主界面

验证时间：2026-08-31 16:02（Asia/Shanghai）

### 自动化门禁

1. JVM 单元测试通过：姓名归一化、空姓名、Unicode 码点上限和重复点击门禁。
2. 目标真机 instrumentation 测试 3/3 通过：
   - 姓名和照片写入应用私有目录后可重载；
   - 仅更新姓名时保留已有照片；
   - 无法解码的伪图片被拒绝。
3. 严格 Android Lint 通过，0 个错误、0 个警告。

### 实机界面与交互

1. 首次启动显示家属设置页；在 1.45 倍系统字体下，标题、说明、照片、姓名输入框和保存按钮均位于可见区域内。
2. 使用临时联系人 `Family` 保存后进入老人首页，照片按钮触控区域为 840 × 840 px。
3. 照片按钮向可访问性树暴露“给Family打视频电话”，姓名和操作提示均完整显示。
4. 连续点击照片只触发一次受控反馈；F03 尚未完成时明确显示“通话服务尚未开启，请家属继续设置”。
5. 强制停止后冷启动成功，临时联系人配置仍能恢复。
6. UI 测试后已清除临时联系人和测试照片，并卸载 instrumentation 测试 APK；KinCall 主应用保留在首次设置页。
7. 验证期间未发现 KinCall 的 `FATAL EXCEPTION` 或 ANR。

结论：F02 通过目标真机功能与可见输出验收。

## F03 受限辅助服务与运行环境授权

验证时间：2026-08-31 至 2026-09-02（Asia/Shanghai）

### 自动化门禁

1. JVM 单元测试通过：可解析完整与缩写组件名，并拒绝空值和相似组件名。
2. 目标真机 instrumentation 测试 5/5 通过，其中两项 F03 契约测试确认：
   - 服务必须由系统 `BIND_ACCESSIBILITY_SERVICE` 权限绑定；
   - 服务 XML 仅允许 `com.tencent.mm`，并声明读取窗口内容和执行手势能力。
3. 严格 Android Lint 通过，Debug APK 与 instrumentation APK 构建成功。

### 实机授权与可见输出

1. 系统包管理器确认辅助服务组件已注册，未授权前全局辅助功能状态为关闭。
2. 应用设置页正确显示“已安装微信”和“KinCall 辅助服务未开启”，并可跳转系统无障碍设置。
3. 用户在华为系统设置中手动开启“KinCall 一键通话辅助”，未使用 ADB 修改安全设置或绕过系统确认。
4. 授权后系统安全设置返回 `accessibility_enabled=1`，KinCall 服务同时出现在 Enabled 与 Bound 列表；能力位为 33。
5. 返回应用后，可见界面正确刷新为“已安装微信”和“KinCall 辅助服务已开启”。
6. F03 服务实现不执行点击、手势或微信启动；自动化状态机未完成时，用户通话请求只显示安全阻断信息。
7. 点击临时联系人 `Family` 前后，前台 Activity 均保持为 KinCall，并显示“自动拨号功能正在准备中”；微信未被启动。
8. EMUI 在应用被系统“强行停止”后会清除其辅助服务授权；应用能检测到失效并要求家属重新授权。F05 恢复策略必须覆盖此设备行为。
9. 原始截图与 UI 树保存在不纳入版本控制的 `artifacts/device-tests/f03/`，设备序列号不写入仓库。

结论：F03 通过目标真机授权、系统绑定、作用域与可见输出验收，可进入 F04 微信状态机开发。
